# Muhammad Akram: Professional IT Portfolio

React + Vite portfolio for the Parallel and Distributed Computing additional activity (University of Sindh, Department of Software Engineering).

**Live site:** add your Vercel URL here
**Author:** Muhammad Akram ([GitHub](https://github.com/AkramSE) · [LinkedIn](https://www.linkedin.com/in/muhammad-akram-se))

## Features
- All 14 required sections plus an interactive thread-pool simulator (parallel computing demo)
- Animated aurora background, cursor spotlight, 3D tilt cards, typing effect, animated counters, scroll reveals
- Project filter and case-study tabs
- Responsive (mobile, tablet, desktop), keyboard accessible, reduced-motion support

## Run locally
```bash
npm install
npm run dev
```
Open the URL shown in the terminal (usually http://localhost:5173).

## Build
```bash
npm run build
```

## Deploy on Vercel
Import the GitHub repo in Vercel. Framework preset: **Vite**. Build command `npm run build`, output directory `dist`. Every push redeploys automatically.

## Structure
- `src/App.jsx`: all sections and components
- `src/styles.css`: styling and animations
- `public/Muhammad_Akram_Resume.pdf`: CV used by the download buttons
